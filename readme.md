# Prediksi Kelulusan Mahasiswa

## Deskripsi
Proyek Machine Learning sederhana untuk memprediksi
status kelulusan berdasarkan IPK dan kehadiran.

## Algoritma
Decision Tree Classifier

## Teknologi
- Python
- Pandas
- Scikit-learn

## Cara Menjalankan
1. Instal library dengan `pip install pandas scikit-learn`
2. Jalankan `python main.py`
3. Masukkan IPK dan persentase kehadiran.

## Catatan
Dataset yang digunakan merupakan data simulasi
untuk pembelajaran.
