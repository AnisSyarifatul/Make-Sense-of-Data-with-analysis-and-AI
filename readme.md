
# Prediksi Kelulusan Mahasiswa Menggunakan Machine Learning

## Studi Kasus
Studi kasus ini membahas prediksi kelulusan mahasiswa berdasarkan IPK dan persentase kehadiran menggunakan algoritma Decision Tree. Program dibuat menggunakan Python untuk mempelajari pola dari data mahasiswa dan memprediksi status kelulusan, yaitu lulus atau belum lulus. Proyek ini bertujuan memahami penerapan Machine Learning dalam bidang pendidikan melalui pengolahan data, pelatihan model, dan pengujian hasil prediksi.

## Tujuan
- Menerapkan Machine Learning untuk prediksi kelulusan mahasiswa.
- Memahami proses pelatihan dan pengujian model.
- Mengetahui hasil evaluasi model menggunakan akurasi.

## Teknologi
- Python
- Pandas
- Scikit-learn
- Visual Studio Code
- GitHub

## Algoritma
Decision Tree Classifier.

## Dataset
Dataset berisi data simulasi mahasiswa dengan atribut IPK, kehadiran, dan status kelulusan.

## Cara Menjalankan
1. Instal library:
   ```bash
   pip install pandas scikit-learn
   ```
2. Jalankan program:
   ```bash
   python main.py
   ```
3. Masukkan IPK dan persentase kehadiran mahasiswa.
4. Lihat hasil prediksi yang ditampilkan.
